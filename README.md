# تمرین طراحی صفحه شخصی با HTML

## شرح تمرین
در این تمرین، یک صفحه وب شخصی با استفاده از HTML طراحی و پیاده‌سازی شده است. هدف از این تمرین، آشنایی عملی با ساختار صفحات وب و استفاده از تگ‌های پایه HTML است.

## بخش‌های پیاده‌سازی‌شده
- نمایش اطلاعات شخصی و تحصیلی با استفاده از لیست‌های تعریفی
- طراحی جدول برنامه هفتگی کلاس‌ها با استفاده از جدول HTML
- نمایش سوابق کاری و تجربیات حرفه‌ای با استفاده از عنوان‌ها، پاراگراف‌ها و لیست‌ها

## مباحث استفاده‌شده
- ساختار اصلی HTML
- عنوان‌ها و پاراگراف‌ها
- لیست‌های تعریفی و لیست‌های معمولی
- جداول و ویژگی‌های `colspan` و `rowspan`
- تگ‌های `strong` و `br`
